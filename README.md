# Free Standalone SEO Keyword & Content Density Counter (.exe)

A fast, lightweight, and 100% offline Windows desktop application designed for writers, copywriters, and SEO specialists to analyze text and HTML files locally for word counts, keyword frequencies, and phrase densities.

Developed by **Muhammad Qasim Aziz** | **[HITS Web SEO Write](https://webseowrite.pk)**

---

## 🚀 Key Features
- **100% Local & Private:** Analyze drafts and HTML web exports securely without cloud server uploads.
- **Smart Stop Word Filtering:** Automatically excludes filler words to highlight top single keywords, bigrams (2-word phrases), and trigrams (3-word phrases).
- **Target Keyword Checker:** Input any focus keyword to instantly calculate exact match counts and density percentages.
- **Multi-Format Support:** Reads `.html`, `.htm`, `.txt`, `.md`, and `.csv` files or raw pasted text.
- **CSV Report Export:** Save structured density breakdown spreadsheets with a single click.

---

## 📥 How to Download & Run
1. Go to the **[Releases](../../releases)** tab on the right side of this repository page.
2. Download the latest `keyword_counter.exe` file.
3. Launch `keyword_counter.exe` on your Windows PC.
4. Select a document or paste text, enter your target keyword, and click **Analyze Content & Calculate Density**!
